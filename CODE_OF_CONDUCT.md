# Community code of conduct

Be respectful, constructive, and welcoming. Discuss ideas and code on their merits. Accept good-faith feedback, respect privacy, and make room for contributors with different backgrounds and experience.

Harassment, discriminatory language, threats, sexualized conduct, doxxing, and deliberate disruption are unacceptable in project discussions, issues, reviews, and other project spaces.

Maintainers may edit or remove harmful content, close disruptive discussions, or restrict participation. Responses should be proportionate, explain the violated expectation when appropriate, and protect privacy.

Report concerns privately to a repository maintainer through the hosting platform when possible. If no private route is available, request a private contact without publishing the incident or identifying details. A dedicated conduct contact must be established before a public community launch.
